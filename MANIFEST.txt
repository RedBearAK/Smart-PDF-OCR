WHAT CHANGES

  The corrected text dump now leads with a provenance line naming the
  document it came from:

      === source: 20260823141532.pdf ===
      === page 1 ===
      ...

  assemble_text() gains an optional source parameter (default "", old
  behavior exactly); cli passes the basename of --input (or --cached as
  the fallback). Downstream tools can name their outputs after the
  document instead of after the generic dump filename -- output-file
  collisions between runs were traced to exactly that. Parsers that split
  on the page markers see the source line as invisible preamble:
  gxy_charges_sheet already skips it by construction, and nothing else
  consumes corrected text.

TESTS

  test_pipeline.py: new test_source_line_leads_the_dump (source line
  first, page 1 marker second, sourceless output byte-identical to
  before). Also registers the pre-existing
  test_page_markers_head_each_page in main() -- it was defined but absent
  from the standalone SCORE list, so it ran under pytest discovery only.
  Standalone: 6/6. Full suite: 127 passed, pyflakes clean. End-to-end:
  real run shows the source line leading corrected output.

COMPANION

  gxy_charges_sheet.py (delivered alongside, lives in python_scripts/, not
  this repo) reads the source line and names its default output
  <source-stem>_charges_<yymmdd>_<hhmmss>.xlsx beside the input; corrected
  files predating this tarball fall back to the input file's stem, still
  timestamped. Explicit -o is unchanged.
